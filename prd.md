# Product Requirements Document (PRD)

## Problem Statement

Users communicating in multilingual and high-pressure situations often face tone anxiety and difficulty expressing intent clearly, especially in Indic language communication workflows.

## Target Audience

- Users who type and speak in Indic languages and English.
- Professionals and students who need context-aware, tone-safe responses.
- Accessibility-first users who benefit from assisted input and contextual suggestions.

## Core Features

1. Voice-to-Text via Gnani Prisma
   - Convert voice input into text suitable for keyboard insertion.
2. Accessibility-based Context Extraction
   - Read surrounding app context (with explicit user permissions) to inform suggestions.
3. Evon LLM Tone Enhancement
   - Refine drafted text for clarity, politeness, and intent preservation.

## Non-Goals (Current Stage)

- Full production integrations.
- Finalized UI/UX and monetization.
- Broad language model optimization.

## Initial Success Criteria

- Project structure ready for parallel AI agent development.
- Native Android service placeholders in place.
- Clear docs for implementation sequencing.
